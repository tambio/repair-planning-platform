# Web Platform for Renovation Planning and Control

## About the Project
This is a diploma project. The goal is to create a web platform that helps people plan renovation works and control time and money.

The platform has two sides:
- **For the builder** — calculate costs, plan the schedule, track expenses.
- **For the client** — see the shopping list, check spending, follow the progress.

The platform uses AI to:
- build a work schedule automatically,
- group expenses by category,
- show plan vs fact analytics.

## Problem
Renovation is not automated well today:
- costs are calculated in Excel or on paper,
- the schedule is only in the builder's head,
- receipts are lost,
- extra spending is found too late.

This causes delays, budget problems, and conflicts between client and builder.

## Target Users
1. **Private builders and masters** — need fast cost calculation, planning, and money control.
2. **Clients** — want to know what to buy, when to buy, and how much is already spent.

## Aim
Develop a web platform for planning and control of renovation works with automatic cost calculation, schedule building, and real expense tracking.

## Expected Outcomes
- Web platform with accounts for builder and client.
- Cost calculation module.
- AI planner.
- Shopping list by stages.
- Receipt upload with categorization.
- Analytics dashboard: plan vs fact.

## Project Scope
**In scope:** cost calculation, material list, schedule, receipt tracking, analytics, AI modules.

**Out of scope:** the renovation work itself, buying materials, legal support, bank integration, mobile app.

## Technologies
- **Backend:** Python (FastAPI)
- **Frontend:** React (Next.js) + Tailwind CSS
- **Database:** PostgreSQL + pgvector
- **AI:** OpenAI API / Gemini, LangChain
- **Planning:** OR-Tools
- **Project management:** GitHub + YouTrack
